## Projects

**[Zenwi](https://github.com/Sindhu0012/Zenwi)** - Smart study tracker with mood intelligence
Published production Android app with a Pomodoro timer, goals, streaks, burnout detection, a yearly activity heatmap and an AI study coach. Built with React Native, Expo, Firebase and Groq (LLaMA 3.1).

**[ClientMind](https://github.com/Sindhu0012/clientmind)** - Relationship intelligence agent
AI agent with persistent memory that recalls client history and briefs you before every interaction. Built as team lead at Hack With Hyderabad 3.0. Node.js, Express, Groq, Hindsight.

**ShieldCircle** - AI family scam protection (ForgeHacks Online 2026)
Protects families from scam messages using a weighted rule engine, link inspection and per-member memory, with explanations in English, Telugu and Hindi. An LLM can raise a verdict's severity but never lower it. Scored 95% on a 40-message labeled evaluation. Node.js, Express, Groq, Hindsight.

**[FitTrack](https://github.com/Sindhu0012/FitnessTracker)** - Fitness and activity tracker
React Native app with per-user authentication, activity logging across seven workout types, streaks, milestone badges and a 7-day calorie chart.

[Zenwi RiskSense](https://github.com/Sindhu0012/zenwi-risksense) - ML prototype for student dropout risk. Caught a data leak (a perfect 1.0 score that came from a hard-coded label rule), then evaluated honestly on 80,000 students with only 2% positives using recall and PR-AUC. Python, pandas, scikit-learn.
